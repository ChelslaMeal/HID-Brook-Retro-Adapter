# HID-Brook-Retro-Adapter
An adapter that lets you connect any HID input device (gamepad, keyboard, etc) to your retro consoles via the Brook Retro Board.

The project is currently under development, and does not have any useable code yet.

## Items Required:
- A Brook Retro Board or Brook Ultimate Plus board (with Retro consoles via RJ45 jacks)

  [https://arcadeshock.com/products/brook-retro-board?variant=12261573787683]
  
  [https://arcadeshock.com/products/brook-ultimate-board-plus-retro-board?_pos=2&_sid=e2a4f5b96&_ss=r]
- An RP2040 board (2035 untested)
  [https://www.amazon.com/dp/B0FPLWV3N4]
- A USB breakout board with a female connector
  [https://www.amazon.com/dp/B09N8X9N4Y]
- A push button for input mapping
  [https://www.amazon.com/dp/B08B1P43XY]
- SSD1306/SSD1309 screen
  [https://www.amazon.com/dp/B0G3849NQJ]

RJ45 terminals + RJ45 crimper + controller cable for your console of choice are also required if making your own cables.

Additionally, an IO Expansion board and additional pushbutton are recommended for L3/R3/Turbo functionality. [https://www.amazon.com/dp/B0F2M5Y2LK]
Basic soldering experience required.
